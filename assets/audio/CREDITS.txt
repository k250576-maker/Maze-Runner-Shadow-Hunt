Maze Runner - Shadow Hunt audio credits

Dungeon Ambience by yd (dungeon002.ogg)
Default exploration soundtrack. Listed as CC0 by the creator.
https://opengameart.org/content/dungeon-ambience

Dark Cavern Ambient by Paul Wortmann (dark_cavern_ambient_001.ogg)
Alternative soundtrack. Listed as CC0 by the creator. This edition fades in and out.
https://opengameart.org/content/dark-cavern-ambient

Deep Dungeon — Fog Saburo
Optional local soundtrack selected with --music deep-dungeon. The supplied
file is an MP3. The local deep_dungeon.mp3 alias is a byte-for-byte copy.
The creator's game redistribution terms could not be verified. Keep the
original and local playback copies out of distributed builds.
https://www.youtube.com/watch?v=kA7c3SpzZDA

Footsteps (footsteps-use-it-again.mp3)
Supplied locally. The creator and redistribution license are unverified.
The game plays one step cropped in memory when this optional file is present.
Keep the supplied recording out of distributed builds.

Stone step (stone_step.wav)
Original synthesized sound made for this project. The shared build includes
this one-step clip for players without the optional local recording.
